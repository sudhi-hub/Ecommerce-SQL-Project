# E-Commerce SQL Project

## Overview
This project demonstrates the design and analysis of an E-Commerce database using MySQL. It covers database creation, table relationships, data insertion, and SQL queries for data analysis.

## Tools Used
- MySQL Workbench
- GitHub

## Database Tables
- Customers
- Categories
- Products
- Orders
- Order_Items
- Payments

## SQL Concepts Covered
- Basic Queries
- Aggregate Functions
- JOIN
- GROUP BY
- HAVING
- Subqueries
- Window Functions
- Date Functions
- CASE Statements

## Project Objective
To practice SQL concepts by building an E-Commerce database and performing data analysis using real-world business scenarios.
